**Event Schema Generator v4.1 - Product+Event Hybrid Schema Generator**

**What it does:** Generates Schema.org compliant JSON-LD for workshops and courses using Product+Event hybrid schema (workshops/courses are both products AND events).

**Required Files:**

**1\. Event CSV File (Required):**

• Export from Squarespace Events ↽ `events_export.csv`

• Must include: `Event_Title`, `Start_Date`, `Start_Time`, `End_Date`, `End_Time`, `Event_URL`, `Event_Image`, `Location_Business_Name`, `Location_Address`, `Location_City_State_ZIP`, `Excerpt`, `Category`, `Workflow_State`, `Tags`, `Published_Date`.

**2\. Event-Product Mappings CSV (Required for offers & SKU):**

• File: `event-product-mappings-*.csv` (generated by chat-bot ingest app)

• Maps event URLs to product URLs and includes `price_gbp` for offers

• Provides SKU extraction (currently from URL slug, will be improved to use products CSV)

• **Without this file:** Events will have price = 0 (data error logged)

**3\. Reviews CSV (Optional - for review enrichment):**

• File: `shared-resources/csv processed/03 – combined_product_reviews.csv`

• Adds aggregateRating and review snippets to events

• Only events with matching product URLs get reviews

**⚽ How it works:**

• Uses `@type: ["Product", "Event"]` hybrid schema (validates with Schema.org)

• Always adds offers (Google requirement) - logs error if price = 0

• Adds SKU to offers object (required for Product+Event hybrid)

• Includes organizer, performer, location with parsed address

• Groups repeating events into EventSeries when enabled

• Only includes published events with future start dates

• Validates all required fields and reports errors/warnings

#### ℹ Understanding Schema Types

**Important:** A page can have MULTIPLE schema types. This generator creates the PAGE-LEVEL schema (what the page is about). Product blocks on the page can have their own Product schemas separately.

**Service** \- Use for:

- Service pages (photography lessons, tutoring, consulting)
- Course/tuition pages (even if they sell products to book the course)
- Pages describing WHAT you offer (the service itself)
- **Example:** "Private Photography Lessons" page - describes the SERVICE, even if there's a product block to purchase it

**Product** \- Use for:

- Product pages (physical products, vouchers, gift cards)
- Pages where the PRODUCT is the main focus
- **Note:** Only use if the page is ABOUT the product, not about a service that happens to sell products
- **Example:** "Gift Voucher" page - the product IS the page content

**ItemList** \- Use for:

- Category/gateway pages that list multiple items
- Pages that link to multiple products or services
- **Example:** "All Photography Courses" page listing multiple courses

**WebPage** \- Use for:

- Informational articles, guides, blog posts
- Pages that are primarily content/information
- **Example:** "How to Choose a Photography Tutor" guide page

Auto-Detection Logic:

Keywords like "course", "tuition", "workshop", "lesson" ↽ **Service**

Keywords like "guide", "tips", "how to", "article" ↽ **WebPage**

Keywords like "voucher", "gift", "buy" ↽ **Product**

Category/list pages ↽ **ItemList**

## Complete Workflow Guide

This guide shows the complete step-by-step workflow for each schema type, verified against the actual implementation.

### Product Schema - Complete Workflow

1. **Step 0 - Setup Check (Automatic):**


    • Checks your setup and starts local server if needed


    • File location: `shared-resources/csv processed/credentials/` (for OAuth)


    • Unlocks Step 1 automatically when ready
2. **Step 1 - Export Products from Squarespace:**


    • `Squarespace ↽ Commerce ↽ Products ↽ Export CSV`


    • Upload file: `raw-01-products-sqsp-export.csv` from: `shared-resources/csv/` folder


    • Step 2 starts automatically after upload
3. **Step 2 - Clean and Normalize CSV (Automatic):**


    • Runs automatically after Step 1


    • Normalizes column names, removes variants, formats data


    • Output: `shared-resources/csv processed/02 – products_cleaned.xlsx`


    • Step 3a starts automatically next
4. **Step 3a - Fetch Google Reviews:**


    • Requires OAuth credentials in `shared-resources/csv processed/credentials/`


    • First time: Browser opens for OAuth authorization


    • Connects to Google My Business API


    • Output: `shared-resources/csv/raw-03b-google-reviews.csv`


    • Step 3b starts automatically next
5. **Step 3b - Merge Reviews (Automatic):**


    • Requires: `shared-resources/csv/raw-03a-trustpilot-reviews-historical.csv` (must exist)


    • Combines Google reviews (from Step 3a) with Trustpilot reviews


    • Filters reviews below 4★


    • Matches reviews to products by URL/name


    • Output: `shared-resources/csv processed/03 – combined_product_reviews.csv`


    • Step 4 starts automatically next
6. **Step 4 - Generate Product Schema:**


    • Reads: `shared-resources/csv processed/02 – products_cleaned.xlsx` and `shared-resources/csv processed/03 – combined_product_reviews.csv`


    • Generates JSON-LD Product schema with reviews


    • Filters products with weak reviews


    • Includes Schema Suppressor v1.3 to prevent duplicates


    • Output: `shared-resources/outputs/schema/products/*_schema_squarespace_ready.html` (one file per product)
7. **Deploy to Squarespace:**


    • Copy schema from generated HTML files in `shared-resources/outputs/schema/products/`


    • Paste into Squarespace product pages (Header Code Injection or Code Block)


    • Validate using Schema Validator tab

### Event Schema - Complete Workflow

1. **Export Events from Squarespace:**


    • `Squarespace ↽ Commerce ↽ Events ↽ Export CSV`


    • Save to: `shared-resources/csv/` folder (files retain original Squarespace export filenames)


    • Required fields: Event\_Title, Start\_Date, Start\_Time, End\_Date, End\_Time, Event\_URL, Event\_Image, Location\_Business\_Name, Location\_Address, Location\_City\_State\_ZIP, Excerpt, Category, Workflow\_State
2. **Generate Event-Product Mappings:**


    • Run chat-bot ingest app to generate mappings


    • File: `shared-resources/csv processed/event-product-mappings-*.csv`


    • ⚽ **Required** \- Maps event URLs to product URLs and includes price\_gbp


    • Without this: Events will show price = 0 errors
3. **(Optional) Prepare Reviews CSV:**


    • Use existing: `shared-resources/csv processed/03 – combined_product_reviews.csv`


    • Adds aggregateRating and review snippets to events


    • Only events with matching product URLs get reviews
4. **(Optional) Prepare Products Excel:**


    • Use existing: `shared-resources/csv processed/02 – products_cleaned.xlsx`


    • Provides actual SKU values (prevents fallback to URL slug)
5. **Upload Files in Event Schema Tab:**


    • Upload Event CSV file


    • Upload Event-Product Mappings CSV (required)


    • (Optional) Upload Reviews CSV


    • (Optional) Upload Products Excel
6. **Configure Options:**


    • Enable/disable review enrichment


    • Set performer name (default: "Alan Ranger")


    • Configure merchant fields (name, ID, URL)
7. **Select Category Filter:**


    • Choose a specific category or "All Categories"


    • Only events matching the filter will be included
8. **Generate Schema:**


    • Click "Generate Event Schema" button


    • Generates Product+Event hybrid JSON-LD schema


    • Includes offers, location, performer, organizer
9. **Deploy to Squarespace:**


    • Copy the generated schema


    • Paste into Squarespace event page (Header Code Injection or Code Block)


    • Best practice: Paste on main events listing page rather than individual event pages


    • Validate using Schema Validator tab

### Best Practices

- **File Naming:** Keep consistent naming conventions (e.g., `01 – products_*.csv`, `02 – products_cleaned.xlsx`)
- **Schema Placement:** Only insert schema relevant to the page (don't paste every product on every product page)
- **Validation:** Always validate using the **Schema Validator** before and after injecting schema
- **Code Format:** Use `<script type="application/ld+json">` inside a code block on Squarespace pages
- **Backup:** Keep copies of generated schema files in `shared-resources/outputs/schema/` folders
